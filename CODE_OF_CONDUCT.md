# Code of Conduct

## Our standards

This project should be a practical, respectful place to work. Contributors are
expected to:

- Be direct, kind, and constructive.
- Assume good intent while still naming problems clearly.
- Respect different experience levels and communication styles.
- Keep critique focused on the work, not the person.
- Avoid harassment, insults, sexualized language, threats, or sustained
  disruption.

## Scope

This code of conduct applies in project spaces, including issues, pull
requests, discussions, and any other community channels connected to `shh`.

## Enforcement

Project maintainers may edit, hide, or remove comments and other contributions
that violate these standards. They may also temporarily or permanently limit
participation for behavior that makes the project unsafe or unproductive.

If you see a problem, contact a maintainer privately when possible. If private
contact is not available, flag the behavior in the relevant platform so it can
be reviewed.

## Attribution

This code of conduct is inspired by common open-source community standards and
is tailored for this project.
