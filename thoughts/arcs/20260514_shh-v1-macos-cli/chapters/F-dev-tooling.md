# Chapter F — Dev tooling

**Type:** conscious
**Depends on:** none

## Executive summary

Reproducible local dev shell plus the contributor command surface declared in the PRD. Conscious because Nix flake design and `install-signed` codesign invocation have judgment calls (which Rust toolchain source, which darwin frameworks to surface, codesign options).

## Files touched

- `flake.nix` (create)
- `flake.lock` (generated by `nix flake update`)
- `justfile` (create)
- `.gitignore` (extend with `result`, `result-*`, `.direnv/`)
- `README.md` (create — minimal quickstart matching acceptance criteria)

## Success criteria

- `nix develop` on macOS opens a shell with `rustc`, `cargo`, `rustfmt`, `clippy`, `just` on PATH. Confirmed via `which` for each.
- `just setup` reports OK when toolchain is present.
- `just fmt`, `just lint`, `just test`, `just build`, `just ci` work inside `nix develop`.
- `just run -- --help` prints the CLI help.
- `just install` runs `cargo install --path .` and places `shh` in `~/.cargo/bin/`.
- `just install-signed` requires `SHH_SIGN_IDENTITY`, performs `cargo build --release`, codesigns with `--timestamp --options runtime --sign "$SHH_SIGN_IDENTITY"`, copies to `~/.cargo/bin/shh`. Errors clearly if `SHH_SIGN_IDENTITY` is unset.
- `just smoke-keychain` runs `cargo run -- doctor keychain` against `__shh_smoke__` profile via `SHH_SERVICE_PREFIX=shh-smoke` and cleans up.
- `README.md` quickstart lists: `nix develop`, `just install`, `shh set OPENAI_API_KEY`, `shh export | eval`.

## Phases

### F.1 — `flake.nix`

- **Goal:** macOS-focused dev shell using `nixpkgs-unstable`.
- **Files & changes:** `flake.nix`.
- **Code:**
  ```nix
  {
    description = "shh dev shell";
    inputs.nixpkgs.url = "github:NixOS/nixpkgs/nixpkgs-unstable";
    outputs = { self, nixpkgs }:
      let
        forSystems = nixpkgs.lib.genAttrs [ "aarch64-darwin" "x86_64-darwin" ];
      in {
        devShells = forSystems (system:
          let pkgs = import nixpkgs { inherit system; };
          in {
            default = pkgs.mkShell {
              packages = [
                pkgs.rustc pkgs.cargo pkgs.rustfmt pkgs.clippy
                pkgs.just
                pkgs.pkg-config
              ] ++ pkgs.lib.optionals pkgs.stdenv.isDarwin [
                pkgs.darwin.apple_sdk.frameworks.Security
                pkgs.libiconv
              ];
            };
          });
      };
  }
  ```
  - Run `nix flake update` to generate `flake.lock`.
  - **Note for executor:** if `security-framework` build fails for missing `CoreFoundation`, add `pkgs.darwin.apple_sdk.frameworks.CoreFoundation` to the dev shell.

### F.2 — `justfile`

- **Goal:** Wraps the contributor commands. PRD-listed targets only.
- **Files & changes:** `justfile`.
- **Code:**
  ```just
  set positional-arguments := true

  default: ci

  setup:
      @command -v cargo >/dev/null || (echo "cargo not on PATH — run 'nix develop'" && exit 1)
      @command -v just >/dev/null

  fmt:
      cargo fmt --all

  lint:
      cargo clippy --all-targets -- -D warnings

  test:
      cargo test --all

  build:
      cargo build

  run *ARGS:
      cargo run -- {{ARGS}}

  install:
      cargo install --path .

  install-signed:
      @if [ -z "${SHH_SIGN_IDENTITY:-}" ]; then echo "SHH_SIGN_IDENTITY not set"; exit 1; fi
      cargo build --release
      codesign --force --timestamp --options runtime --sign "$SHH_SIGN_IDENTITY" target/release/shh
      install -m 0755 target/release/shh "$HOME/.cargo/bin/shh"

  smoke-keychain:
      SHH_SERVICE_PREFIX=shh-smoke cargo run -- doctor keychain

  ci: fmt-check lint test

  fmt-check:
      cargo fmt --all -- --check
  ```
